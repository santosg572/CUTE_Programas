Solucion de Ecuación Diferencial Ordinaria de 2er orden¶

  1. Dada la ecuación difdrencial:

\[x'' + b x' + cx + d = 0\]

con condiciones iniciales \(x(0) = x_0\) y \(x'(0) = x_1\) encontrar su solución.

  1. Soluciones particulales de \(x'' + b x' + cx = 0\)

Consideremos la ecuación \(x^2+bx+c=0\)

La soluciones de esta ecuacion son:

\[r_{1,2} = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\]

Luego la solucion de la ecuación (2) es

\[y(t) = A e^{r_1t} + B e^{r_2t}\]

Luego la solución general de la ecuación 1 es:

\[y(t) = A e^{r_1t} + B e^{r_2t} - \frac{d}{c}\]

Establescamos las condiciones iniciales y(0) = 1 y y'(0) = 0

Lugo obtenemos:

\[ \begin{align}\begin{aligned}y(0) = A + B - \frac{d}{c} = 1\\y'(0) = Ar_1 + Br_2 = 0\end{aligned}\end{align} \]

entonces

\[ \begin{align}\begin{aligned}-Ar_1 - Br_1 = -r_1(1 + \frac{d}{c})\\Ar_1 + Br_2 = 0\end{aligned}\end{align} \]

luego:

\[ \begin{align}\begin{aligned}B = \frac{-r_1(1 + \frac{d}{c})}{r_2-r_1}\\A = -\frac{r_2}{r_1} B\end{aligned}\end{align} \]

Solución analítica

\[ \begin{align}\begin{aligned}x_1 = x\\x_2 = x'\end{aligned}\end{align} \]

entonces

\[ \begin{align}\begin{aligned}x'_2 + bx_2 + cx_1 + d = 0\\x'_1 = x_2\end{aligned}\end{align} \]

Luego:

\[ \begin{align}\begin{aligned}x'_2 = -bx_2 - cx_1 - d\\x'_1 = x_2\end{aligned}\end{align} \]

Luego

\[\begin{split}\left( \begin{matrix} x'_2\\ x'_1 \end{matrix} \right) = \left( \begin{matrix} -b & -c\\ 1 & 0 \end{matrix} \right) \left( \begin{matrix} x_2\\ x_1 \end{matrix} \right) + \left( \begin{matrix} -d\\ 0 \end{matrix} \right)=\end{split}\]
